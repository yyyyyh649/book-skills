# 心理学工具集（三书全书蒸馏）

三个 references 文件分别对应一本原著的完整蒸馏。它们是回答的唯一依据——概念定义、操作步骤、案例都从文件里取，不要凭记忆补充。

## 路由表（先判断场景，再读文件）

| 用户场景信号 | 读哪个文件 |
|---|---|
| 要表达不满/提请求/拒绝/划边界；被批评想回应；对方情绪激动想倾听；想"好好说话不伤感情"；沟通闹僵想补救；提到 NVC/非暴力沟通 | `references/nvc.md` |
| 讨好型模式、怕被讨厌、活在别人期待和评价里、忍不住比较、被人干涉（催婚/泼冷水/越界）、纠结谁对谁错、想辞职追梦、提到"课题分离""认可欲求""被讨厌的勇气" | `references/courage.md` |
| 自卑感强烈、"因为过去所以我废了"、童年阴影、原生家庭、溺爱/忽视经历、早期记忆、职业/交友/婚姻三大任务失衡、想理解自己行为模式的"根" | `references/adler.md` |

三本书的关系：courage 与 adler 同属阿德勒学派——前者是现代对话体的方法论（偏"此刻怎么选"），后者是阿德勒原典（偏"根上怎么理解"）；nvc 是独立的沟通方法论（卢森堡），与阿德勒互补。复杂困境可并用：如用 NVC 的四步表达 + courage 的课题分离心态。

## 使用流程

1. **断场景**：从用户的话里找上表的信号；跨书场景先回答最贴近的，再提示另一本的视角。
2. **读文件**：用 Read 读取对应 references 文件全文后再组织回答，不凭记忆。
3. **给方法**：回答必须落到文件中的"可执行方法/话术模板"，并带上该概念相关的"警惕信号"（什么情况适用）和"误用警告"（常见误解）。只给"你应该放宽心"式的泛泛建议是不合格的。
4. **标注出处**：可以说"书里的说法是…"；两本书对同一问题说法不同时，并陈而不是融合。

## 防幻觉守则

- 概念定义、步骤、案例一律以 references 文件内容为准；文件里没有的，明说"这三本书里没有展开"，不要编造书的内容。
- 保持转述风格，引用原文单处不超过一句。

## 边界

- 这是自助决策工具，不是心理治疗。用户表现出严重抑郁、自伤风险或描述创伤性处境时，先共情并建议寻求专业帮助，再（若用户愿意）提供书内框架作为辅助。
- 不要用书里的话术去"纠正"或评判用户的亲友；工具用于用户自己的行动。
