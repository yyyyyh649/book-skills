# 历史参考（三书全书蒸馏）

三个 references 文件分别对应一部通史原著的完整蒸馏，是回答的第一依据。

## 三本书的分工与路由

| 问题类型 | 读哪个文件 | 这本书的视角 |
|---|---|---|
| 中国史叙事：史前到当代的文化、社会、经济、日常生活 | `references/wanggu.md` | 许倬云的文化史：从"中国的中国"到"东亚的中国"再到"世界体系中的中国"，重小民生活与经济网络 |
| 中国制度史：政府组织、选举、赋税、兵制、皇权相权 | `references/zhidu.md` | 钱穆的制度专史：汉唐宋明清五讲，每项制度的用意与流弊并观 |
| 世界史/全球史：文明兴衰、跨文明比较、全球格局演变 | `references/quanqiu.md` | 斯塔夫里阿诺斯的全球史观：连接与互动、反西方中心论 |
| 交叉问题（明清与世界体系、中西制度对比等） | 先 `wanggu.md` 后 `quanqiu.md`，或 `zhidu.md` 对照 | 两边都读再综合 |

## 三种方法论（回答"为什么"时选用其一或并陈）

1. **全球史观（斯塔夫里阿诺斯）**：把事件放进跨文明网络解释；警惕把欧洲经验当普遍规律。
2. **文化圈与大小传统（许倬云）**：看文化圈层的扩张消化、上层思想与民间生活的互动、经济网络对政治的整合。
3. **制度评价法（钱穆）**：分清"历史意见"与"时代意见"；每项制度同时讲用意与流弊；拒绝用"专制黑暗"四字整体抹杀传统政治。

## 防幻觉守则

- 具体年代、制度名、数据以 references 文件为准；文件未覆盖的时期，明说"参考书未覆盖此段"，可再给通识性回答并注明这是书外知识。
- 区分三层：史实 → 作者论点（必须标注"许倬云认为/钱穆认为/斯塔夫里阿诺斯认为"）→ 多家争论（标注为书中提到的分歧）。
- 保持转述，引用原文单处不超过一句。

## 覆盖范围

- 中国：史前→当代（wanggu.md）；制度：汉→清（zhidu.md）。
- 世界：史前→当代（quanqiu.md）。前半依据第7版修订版、1500 年后依据第7版新校本，文件内已按时间归并。
